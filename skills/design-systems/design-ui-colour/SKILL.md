# Design UI colour and dark mode

Gather the published theme values, supported modes and a representative component. For a new product, use the supplied brand colours and mark proposed additions. Keep existing token names (shared names for design values) when the project has them.

1. List actual colour jobs on the chosen screen. Map page, panel, text, link, primary action, focus and relevant status roles to values. Add shades when a component or state needs a different pairing.
2. Apply the roles to a complete example. For a failed payment, specify the message, text colour, background, border and recovery action. Keep the failure identifiable through its wording or symbol as well as colour.
3. For dark mode, map the same roles to the dark palette. Inspect raised panels, overlays, logos and chart marks on their actual backgrounds. Transparent layers can change the resulting colour.
4. Measure contrast for the foreground and adjacent background in the states used. Record the pair, measured ratio, applicable project target and result. If only a brief or screenshot is available, label estimated values and list the pairs that need measurement.

Deliver a role table with existing names, values per supported mode, component examples and the contrast results available.

# Design UI typography

Collect the project fonts, existing text styles and real strings from the screen. Include a paragraph for a reading page, or a dense row with actual units for a dashboard.

1. Assign a job to each style. Start with body, heading and label. Add a separate role when the content needs it, such as numbers that must align down a table.
2. Set family, size, weight and line height for each role. Apply the choices together to one screen. Check whether a heading reads as the start of its section and whether a secondary label is still legible.
3. Size the reading column using a representative paragraph. For Latin body copy, try roughly 45–75 characters per line and inspect actual wrapping. On the web, a width such as `65ch` is a starting estimate. Short form labels and numeric cells need their own widths.
4. Try the longest heading, a multiline error and enlarged text at a narrow width. Allow controls and rows to grow. Record where wrapping changes meaning or hides the next action.

Deliver a style table with one example string per role. Include column width guidance, any size changes across widths, and the cases that still need rendering.

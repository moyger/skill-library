# Define UI illustration

Start with the screen, the message, available brand artwork and the space the image can occupy. Identify what the illustration helps someone recognise. Keep instructions and recovery actions readable on their own.

1. Specify the subject and composition at the intended size. For an empty booking list, a simple calendar with an open date can accompany the first-booking action. Distinguish a new account from a failed load in the surrounding copy.
2. Extract repeatable rules from approved artwork. Describe shapes, stroke width at display size, corner treatment, perspective, colour roles and detail level. When a reference is unavailable, label the proposed direction as a choice.
3. Describe the crop at narrow and wide sizes. Check which details disappear at the smallest size and which edges disappear against each supported theme. Specify an alternate crop or simplified drawing when needed.
4. State whether the image adds information. Give informative images a short text equivalent. Mark purely decorative images so assistive tools can skip them.

Deliver an art brief with the intended placement, dimensions or aspect ratio, subject, drawing rules, colour roles and acceptance checks. Identify any source assets the illustrator still needs.

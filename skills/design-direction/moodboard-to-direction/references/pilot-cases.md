# Pilot cases

Use the same brief and images in each assistant when comparing results. The [worked examples](worked-examples.md) illustrate the expected decisions. Run the cases below to collect evidence.

| Scenario | Give the agent | Look for |
| --- | --- | --- |
| Workshop booking page | A fictional class schedule and reference images you can share | The recommendation helps someone choose an available session on a phone. It preserves the supplied dates and capacities. |
| Library returns desk | Sample book records, one missing due date and two layout references | The recommendation explains how to find the oldest dated return and locate records that need follow-up. |
| Inaccessible reference | A frame link the assistant cannot open | The assistant asks for an export and reports which design decisions need the missing image. |

For each run, record one decision tied to a visible detail, the trade-off between the proposed directions and a check someone could perform on the first frame.

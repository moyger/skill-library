# Screen Critique

Identify who uses the screen and what they came to do. Inspect the actual frame, screenshot or running page. Record the width and state when known. If the link is inaccessible, ask for a screenshot of the relevant screen.

## Follow the task

1. Start where the visitor starts. Trace their attention from the strongest element to the information they need and the action they can take. Compare the action label with the next visible step.
2. Check continuity (how alignment guides the eye) and proximity (which items look related because they sit close together). Look for a label that reads as a photo caption, a value paired with the wrong row, or a break in the path to an action.
3. Read actual headings, labels and body copy at the intended size. Check wrapping, emphasis and whether headings are visually closer to their own content. Inspect colour, brand assets and control states where they affect the task. Use the design file or rendered values for exact measurements.
4. Record what works and why. Distinguish a visible fault, such as cropped artwork, from a prediction, such as visitors overlooking a link. A static frame supports visual observations. Claims about clicks, keyboard use or user behaviour need other evidence.

## Return a decision

Lead with the change that matters most to the task. For each finding, name the element, evidence, likely consequence, suggested change and a way to judge it. For a proposal, say what a comparison would tell us. A screen with few problems can have a short review. Finish with a specific detail worth preserving.

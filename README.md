## Design skills

Choose a task below, or go to the [setup guide and example prompts](START-HERE.md) to use these skills across projects in Codex and Claude Code.

### Choose a direction · Design direction

Start here when you have references you like and need to decide what to borrow for your own project.

- [Moodboard to Direction](skills/design-direction/moodboard-to-direction/SKILL.md) compares ways to use your references and recommends a direction for the first screen.

### Design or fix a screen · UI design

Use these skills when you know what someone needs to do and want to shape the screen they will use.

- [Design a Screen Layout](skills/ui-design/design-screen-layout/SKILL.md) turns a brief into a layout with a reading order, a main action and a plan for narrow screens.
- [Design a Data View](skills/ui-design/design-data-view/SKILL.md) helps you choose a chart or table based on the question the reader needs to answer.
- [Define UI Illustration](skills/ui-design/define-ui-illustration/SKILL.md) briefs artwork for a specific part of the interface, such as an empty booking list.
- [Fix a Design Finding](skills/ui-design/fix-design-finding/SKILL.md) corrects a specific issue and compares the result with the original at the size where it appeared.

### Make screens feel consistent · Design systems

Start here when the same choices recur across pages, such as how to style a heading or show an error.

- [Design UI Typography](skills/design-systems/design-ui-type/SKILL.md) sets text styles and checks how real headings, labels and paragraphs wrap.
- [Design UI Colour and Dark Mode](skills/design-systems/design-ui-colour/SKILL.md) assigns colours to actions, text and states, and checks contrast where those colours appear together.

### Decide what to improve · Design review

Bring an existing screen and the task a visitor came to complete. Choose the review that matches your question.

- [Screen Critique](skills/design-review/screen-critique/SKILL.md) examines what draws attention, what looks related and what could make the next action clearer.
- [Review an Adaptive Interface](skills/design-review/review-adaptive-ui/SKILL.md) follows the same task across screen sizes, input methods or platforms to find where it breaks.

## Maintaining the library

Edit each skill in its own folder. Keep examples and trial results beside the skill they explain, so they travel with it when someone installs it. Put shared setup instructions and the roadmap in [START-HERE.md](START-HERE.md). For naming, attribution and contribution rules, see [the contributor guide](AGENTS.md).
